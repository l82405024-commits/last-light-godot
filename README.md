# 🏙️ Последний Свет (Last Light) — 3D Заброшенный Город

> Атмосферный вертикальный срез игры на **Godot 4.6** с объемным туманом, процедурными руинами, шейдерами разрушения и передовыми механиками исследования.
> Создано в тандеме двух ИИ-напарников: **Antigravity** (Tech Lead / Архитектор) и **DeepSeek V4.1 Flash** (Core Coder via OpenCode).

---

## 🎮 Ключевые механики

1. **Динамический FPS-контроллер (`CharacterBody3D`)**:
   * Инерция, плавный разгон и торможение.
   * Синусоидальное покачивание камеры при ходьбе и беге (**Head Bobbing**).
   * Прыжки, спринт на `Shift` и приседание на `Ctrl`.
2. **Тактический фонарик (`SpotLight3D`)**:
   * Включение/выключение на клавишу `F` с щелчком тумблера.
   * Расход и регенерация аккумулятора с индикатором на HUD.
3. **Сонар-сканер окружения (`Q`)**:
   * Сферическая расширяющаяся световая волна с френелевским шейдером (`scan_wave.gdshader`).
   * Звуковой импульс обнаружения скрытых объектов.
4. **Интерактивные объекты и лор (`E`)**:
   * Дневники выживших с окном чтения и историей гибели города.
   * Подстанции и электрогенераторы, зажигающие мягкий свет в кварталах.
5. **Процедурный аудио-синтезатор (`SoundSynth`)**:
   * Генерация завываний холодного ветра в реальном времени через `AudioStreamGenerator`.

## ⌨️ Управление

* **WASD / Стрелки** — Перемещение
* **Мышь** — Осмотр
* **Shift** — Спринт (быстрый бег)
* **Ctrl / C** — Приседание
* **Пробел** — Прыжок
* **F** — Фонарик
* **Q** — Сонар-сканирование города
* **E** — Взаимодействие (записки / генераторы)
* **F11** — Полноэкранный режим
* **ESC** — Пауза / освобождение курсора

## 🛠️ Запуск проекта

Откройте **Godot Engine 4.6**, нажмите **«Импорт»** (Import) и укажите файл `project.godot` из этой папки.
Либо запустите через терминал:
```bash
Godot_v4.6-stable_win64.exe --path .
```
